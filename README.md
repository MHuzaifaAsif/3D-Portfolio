## ✨ Key Features

- **🎮 Interactive 3D Canvas Elements**
  - **Retro Workstation Canvas**: Dynamic 3D computer workstation featuring realistic lighting, shadows, and interactive orbital controls.
  - **3D Floating Earth**: Rotating photorealistic Earth model with smooth camera transitions in the contact section.
  - **3D Tech Spheres**: Interactive polyhedral 3D balls with decaled technology icons and physics rotation.
  - **Deep Space Stars Background**: Optimized dynamic particle starfield rendering continuously across the background.

- **💼 Comprehensive Career & Education Timeline**
  - Interactive career timeline documenting experience at **FAST-NUCES**, **Uworx**, **DevHub**, and **Paklogics**.
  - Detailed academic timeline for Bachelor of Science in Software Engineering at **FAST-NUCES**, **GMGC**, and **Hira Public High School**.

- **🧩 Interactive Skills Bento Grid & Modal**
  - High-impact skill cards categorized into Full-Stack Development, Manual QA, Automation Testing, and Data Analysis.
  - Interactive "View All Skills" modal offering categorized technical breakdowns with proficiency indicators.

- **🚀 Featured Engineering Projects**
  - High-resolution project showcase with live demo links, source code repositories, and dynamic color-coded borders matching project palettes.
  - Covers Full-Stack Web Development, Mobile Test Automation (Appium/TestNG), RAG AI Assistants (published in IEEE Xplore), and Big Data analytics.

- **📄 Embedded Resume System**
  - One-click modal viewer with built-in instant download button for Muhammad Huzaifa's latest curriculum vitae.

- **📬 Resilient Contact System**
  - Serverless API integration via Vercel Edge functions with Resend and Google reCAPTCHA v3 protection.
  - Direct quick-contact options via **WhatsApp**, **Direct Email**, and **Phone**.

- **📱 Fully Responsive Design**
  - Seamlessly adapted for mobile phones, tablets, laptops, and ultra-wide desktop monitors.

## ⚡ Getting Started Locally

### 1. Clone the Repository
```bash
git clone https://github.com/MHuzaifaAsif/3D-Portfolio.git
cd 3D-Portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Setup Environment Variables
Create a `.env` file in the project root:
```bash
cp .env.example .env
```

Configure your environment variables as needed:
```env
# Google reCAPTCHA v3
VITE_RECAPTCHA_SITE_KEY=your_recaptcha_site_key
RECAPTCHA_SECRET_KEY=your_recaptcha_secret_key

# Resend Email Service
RESEND_API_KEY=your_resend_api_key
RESEND_FROM_EMAIL=your_verified_sender_email
CONTACT_TO_EMAIL=mhuzaifa.asif412@gmail.com
CONTACT_SITE_URL=https://huzaifa-portfolio-gamma.vercel.app
```
> **Note**: The portfolio functions fully even without API keys; direct email, phone, and WhatsApp communication options remain accessible out of the box.

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 5. Build for Production
```bash
npm run build
```
Generates an optimized production bundle inside the `dist/` directory.

## ☁️ Deployment on Vercel

1. **Push to GitHub**:
   ```bash
   git add .
   git commit -m "Update portfolio"
   git push origin main
   ```

2. **Deploy via Vercel**:
   - Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
   - Import `MHuzaifaAsif/3D-Portfolio`.
   - Select framework preset: **Vite**.
   - Build Command: `npm run build` | Output Directory: `dist`.
   - Add your production environment variables in the Vercel Dashboard.
   - Click **Deploy**!
